# 🥟 UMKM Website — Dapur Berkah

A modern, responsive landing page and product showcase for Indonesian culinary UMKM businesses. Built with React 18, TypeScript, Tailwind CSS, Lucide Icons, and Vite.

Repository: https://github.com/0xyz-exe/UMKM-Website

## Features

- **Responsive Design**: Optimized for smartphones, tablets, and desktop displays.
- **Interactive Menu Catalog**: Browse snack specialties with detailed descriptions and pricing.
- **Direct WhatsApp Ordering**: One-click order routing directly to merchant chat.
- **Business Identity**: Operating hours, store location, social proof, and FAQs.

## Tech Stack

- **Frontend**: React 18, TypeScript
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Build Tool**: Vite

## Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation
```bash
git clone https://github.com/0xyz-exe/UMKM-Website.git
cd UMKM-Website
npm install
npm run dev
```
